# Sales-Performance-Dashboard


## 📊 Project Overview

This project analyzes retail sales data to understand overall sales performance, supplier performance, item-type contribution, and monthly sales trends.

The project uses Python for data analysis and Microsoft Power BI to create an interactive dashboard that presents key sales metrics and business insights.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## 🎯 Project Objectives

- Analyze overall retail sales performance
- Identify top-performing suppliers
- Analyze sales contribution by item type
- Track monthly sales trends
- Compare retail sales with warehouse sales
- Build an interactive dashboard for business analysis

## 📈 Dashboard Features

### Key Performance Indicators

- **Total Retail Sales:** $208K
- **Warehouse Sales:** $823K
- **Total Sales:** $1M
- **Total Items:** 16K

### Interactive Analysis

- Supplier filter
- Item Type filter
- Month-wise filter
- Top 10 Supplier analysis
- Sales by Item Type
- Monthly Sales Trend
- Retail Sales vs Warehouse Sales by Month
- Detailed Supplier and Item Type sales table

## 🔍 Key Insights

- Total sales across the analyzed data are approximately **$1M**.
- Retail sales account for approximately **$208K**.
- Warehouse sales account for approximately **$823K**.
- The dashboard contains approximately **16K total items**.
- **Anheuser Busch Inc** is the top-performing supplier in the Top 10 Supplier analysis.
- **Miller Brewing Company** is the second-highest supplier by sales.
- Beer contributes the largest share of sales among the analyzed item types.
- Monthly sales trends show noticeable variation across January, March, July, and September.
- The dashboard allows users to compare retail and warehouse sales across different months.
